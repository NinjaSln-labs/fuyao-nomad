# 只读审计技能引用（示例）

本目录演示槽位 `capabilities` 如何引用 harness 无关技能。

- 绑到 roster 槽位：`capabilities: [skills/audit-readonly]`
- 实际技能内容应在 `skills/<name>/SKILL.md` 按 Cursor/其他 harness 规范挂载

## 用途

- 调研去权威化提醒
- 审计 findings 格式（severity / fixed / recorded / open）

见 [audit-by-flow-weight.md](../../../../docs/design/audit-by-flow-weight.md)。
