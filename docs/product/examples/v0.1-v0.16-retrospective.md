## 4. 失败与假完成

1. **规则壳冒充 AI**：intent 含「AI」，规格写成「MVP 不依赖大模型」，页面可开即标 done。  
2. **审计假阳性**：只对照已漂移规格，未对照原始 intent。  
3. **无 Key 仍可「完成」**：补了 `/api/advise` 管线后，未配置密钥仍不撤回 milestone。  
4. **过程失误**：发现问题后继续堆产品补丁，而非先记 blocker / RCA（后已纠正）。
