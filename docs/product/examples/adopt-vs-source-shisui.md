> 源仓只读对照 · 接手仓薄切片 · v0.29

| 维度 | 源仓 `shisui` | adopt `fuyao-adopt-shisui` |
|------|---------------|----------------------------|
| **范围** | Python CLI · 入门/机会卡/探针猎场 | 单文件 Mock · draft/evidence/G1/recommend |
| **阶段** | 规格定稿 + CLI v0.2 | 扶摇 **中** 档 s1–s3 |
| **身份** | G1–G5 硬门 · 用户三态裁定 | `ic-evidence-gate`（G1-lite） |
| **审计** | 产品测试 / HANDOFF | `.agents/audit/` design+impl+CQ |

| **硬门** | G1–G5 全过才可行动推荐 | **仅** G1-lite（≥2 信号 · ≥2 类型） |

## 对齐点

- 无出处空想不得进「可行动」推荐  
- 证据可点开（`ref`）· 多类型信号

## 有意差异

- adopt **不**实现 G2–G5、档案 fit、探针/HN、完整机会卡 Schema  
- dogfood 为合成切片；本仓 **显式引用源 entry-gates** 并写本对比表

## 源仓纪律

本 adopt 会话 **不**修改 `shisui` 任何文件。
